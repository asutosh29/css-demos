# Lecture Demos

A simple, flat-themed interactive demo website designed for teaching HTML and CSS fundamentals. 

## Usage

This project is built using vanilla HTML, CSS, JavaScript, and Vite.

To run the development server locally:

1. Install dependencies (if any, though it's primarily static vanilla code):
   ```bash
   npm install
   # or
   bun install
   ```

2. Start the dev server:
   ```bash
   npm run dev
   # or
   bun dev
   ```

3. Open the provided `localhost` URL in your browser.

## Featured Demos

This project includes the following hands-on interactive demonstrations:

1. **Positioning** - Learn how `static`, `relative`, `absolute`, `fixed`, and `sticky` positioning affect element placement using X/Y coordinate sliders.
2. **Font Sizing** - Understand why `px` is rigid and how `rem` and `em` provide scalable, accessible typography that respects root font sizes.
3. **Display & Visibility** - Explore `inline`, `block`, and `inline-block` layout flows, and visualize the difference between `visibility: hidden` and `display: none`.
4. **The Box Model** - Visualize the difference between `content-box` and `border-box` sizing models with live interactive dimension sliders and computed math formulas.
5. **Flexbox** - Master 1-dimensional layouts by controlling the `flex-direction`, `justify-content`, `align-items`, and `flex-wrap` of a flex container.
6. **CSS Grid** - Master 2-dimensional layouts by controlling rows, columns, gaps, and structural alignment inside a grid container.
7. **Selectors & Specificity** - Understand how CSS resolves conflicts when multiple selectors target the same element using a specificity calculator.
